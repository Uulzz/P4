Halo, nama saya Miftahul Shidiq, siswa RPL XI dari Tamansiswa 2 Jakarta Pusat.

Awalnya cuma iseng, mulai dari hal seperti VIRTEX (virus text) yang biasa dipakai buat ngerjain temen. Eh ternyata seru, malah bikin penasaran terus. Dari situ saya belajar pelan-pelan: HTML, CSS, Python, Lua, sampai ngurus database.

Buat saya, coding itu bukan cuma skill” tapi cara menuangkan ide jadi sesuatu yang beneran bisa dipakai orang lain.

Karya

Pengembangan game di Roblox Studio dengan bahasa pemrograman Lua. Meliputi game system seperti inventory, shop, quest, hingga mekanik UI lewat ScreenGui. Proyek ini melatih logika scripting, sistem event, dan penyusunan kode yang rapi.

Toko online sederhana yang dibangun murni dengan HTML dan CSS. Berfokus pada layout yang rapi, kartu produk, dan tampilan yang nyaman di mata pengguna. Cocok jadi dasar belajar struktur halaman web dan styling modern.

Eksperimen pembuatan game sederhana dengan Python, mulai dari game tebak angka sampai game arcade kecil. Proyek ini melatih pemahaman logika, loop, dan pemecahan masalah lewat pemrograman.
